같이 고친 것, 그리고 안 바뀐 것
  • note 편집(프로필에서 노트의 Edit)과 profile 편집(Edit this person)도 같은 설정이 빠져 있어서 같이 고쳤어요. 맨 아래 Save changes / Delete까지 키보드가 올라온 채로 스크롤돼요.
  • New note(쓰는 화면)는 원래 잘 됐어요. 이제 네 화면이 한 설정을 같이 써서, 새 화면이 하나만 빼먹는 일이 없어요.
  • 안 바뀐 것: 화면 내용, 버튼, 문구는 그대로예요. 팔로업 초안 시트는 원래 잘 돼서 손대지 않았어요.
