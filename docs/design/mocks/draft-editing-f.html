Option F - Ask, then edit (final)

Owner's design, finalised 2026-10-30. One box size on every screen; under box B always the hint, the chat line, then Open Messages - the keyboard opening or closing is the only difference. Edit Andy's text and send, with or without a line for Andy; the arrow is on whenever there is something new. Andy never changes key details you wrote (days, times, names, numbers) and doesn't announce it. ‹ › steps through every version while the sheet is open; Close deletes them all. No tone or format controls. Light mode, tokens as in theme.ts.
