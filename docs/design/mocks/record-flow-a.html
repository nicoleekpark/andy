What this option is

Only one thing changes on record--ready: mic-button keeps its full-width pill but is the only filled control on screen; scan-card-button and type-instead-button drop to plain text, side by side, below it. Today's three stacked pills of near-equal weight become one pill and a quiet row — the Von Restorff effect: the one thing drawn differently is the one thing read as "the main thing to do".

about-field

about-field is an ordinary field: same label style, same underline, same placeholder colour as every other field in review — recognition over recall, because the person has already learned this shape there. It sits above the body on both doors (brief R9, option a), so a misheard name can be fixed before anything is read, on voice as well as typing.

Declared (R7)

From Jordan Lee's page, the field itself holds "Jordan Lee" — still a real, editable field, not a locked label — with a small Change link beneath it. Editing the text directly un-declares it, exactly as R3 asks; tapping Change re-opens the suggestion list without having to clear the text by hand first.

Accessibility

  • about-field's placeholder uses colors.placeholder on paper, 5.0:1 — an existing pairing, nothing new.
  • Suggestion rows: colors.edge border, 3.2:1 (WCAG 1.4.11); each row is a minimum of 44pt tall even when its label is one short name.
  • VoiceOver order: field label → field value → suggestion count ("2 people found") → each suggestion row, in that order; the count is announced without moving focus off the field, per brief §8.
  • Listening is said in words ("Stop" replaces "Record"; live words appear) — no colour change on the mic button, unlike today's build, which turns it alert red while listening. See the note at the foot of this document.

A design-system note, not part of this option: the shipped record--listening currently colours mic-button with colors.alert while recording (capture-screen.tsx, the recording style). STYLE.md reserves alert for errors and the three earned deletions, and this brief's own layout guidance (§6) says listening must be unmistakable without colour. This mock (and the other two) show mic-button--listening in the same moss as always, carrying the change in its label and the live words alone — worth fixing in the same PR as whichever option ships.
