거절 뒤에는 다시 묻지 않아요

  • 앱을 열 때는 절대 안 물어요. 처음 묻는 건 사용자가 처음 Let Andy read it · Photo · Ask · Draft를 누를 때예요(A4).
  • Not now는 서버에 기억돼요(aiDeclinedAt). 다른 폰, 재설치 뒤에도 같아요.
  • 거절한 사람: Write 화면의 주 버튼이 Save as written(A5, B2, C3). 시트는 뜨지 않아요. Let Andy read it은 작은 글자로만 남고, 직접 눌렀을 때만 물어요.
  • Ask · 사진 · 초안은 AI 없이는 할 수 없어서, 누르는 순간에만 물어요. 그 외에는 조용해요.
  • 다시 켜기: Settings → What Andy sends → Allow.

바뀐 점

  • About who가 Write 화면 맨 위에 있어요. AI를 허락했으면 선택(비우면 AI가 찾음, 적으면 힌트), 거절했으면 필수. 사람 페이지에서 시작하면 미리 채워져요.
  • A4→A5의 별도 화면이 없어졌어요. 거절한 사람은 Write 화면에서 바로 Save as written.
  • 본문은 줄글, 사실 목록(What to remember)은 따로 있고 선택이에요. 원문과 정리본을 나누는 지금 구조 그대로예요.
  • 시트 문구: "Read it only to do this for you. They don't train on it, and delete it within 30 days."
  • 다시 여는 결정: #165의 "About who? 칸 없는 Write 화면".
  • AI 없이는 빠져요: 글 속 다른 사람(Also came up)의 자동 연결, Ask, 사진 읽기, 초안.
