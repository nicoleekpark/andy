Option C - Ask in the page

One page, no instruction field anywhere. To have Andy write or change something, you put a small "ask" into the text exactly where it belongs, then press one button. An ask is typed words in a pill: it is the instruction, so what is outside pills is always your message (rule 2 stays clean). With no asks, the same button tidies the whole text. Copy only; nothing is sent.
