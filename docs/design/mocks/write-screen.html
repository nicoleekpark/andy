What's on the screen

Title "New note", the same as voice. Back is the chevron alone (#153).

About Priya appears only when opened from her page, the same line the voice screen uses. The note goes to her, and anyone else named becomes a mention.

The body is the whole screen: one serif field with the review screen's underline. The cursor is in it on open and the keyboard is up.

Paste is iOS's own: long-press the body (or tap it again) → Paste. The dark bubble in the mock is that system menu, drawn only to show where it appears; it is not something Andy adds. Pasting through it never asks "Allow Paste?". The placeholder already says "Write or paste", so no button is needed to say it.

Let Andy read it is the only button: disabled while empty and while over the limit. Offline it becomes Keep this note, with the line already decided for the outbox.

Leaving

Back with nothing written leaves without asking. Back with words asks "Discard this note?". If iOS closes Andy instead, the words are kept and offered on home (#159/#161).

Too long

A note has a 12,000-character limit, the same as voice. A count appears only near the limit (last 1,000). Over it, the server's own line shows and Read is disabled, so a long paste is never cut silently.

New names

write screen: write-about, write-body, write-count, write-read-button (offline: keep-note-button), write-discard-alert. Replaces record--typing and its "Stop typing".
